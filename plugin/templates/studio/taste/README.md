# taste — 審美眼

スタジオの中で唯一、使うほど価値が上がる場所。ツールは真似されても、ここに積んだ判断は真似されない。

| ファイル | 中身 | 誰が書くか |
|---|---|---|
| `rules.md` | 判断基準。1行1ルール、理由と出典つき | librarian（人間のレビューから）。手書きも可 |
| `references/good/` | 「これが正解」の画像。ファイル名に理由 | librarian（人間が褒めた・そのまま通した案件から） |
| `references/bad/` | 「これは通したくない」の画像。ファイル名に理由 | librarian（人間が大きく手直しした案件から） |
| `pairs.md` | 二択の記録（A と B なら A、決め手） | librarian（人間が方向性を選び直した、比べて評したとき） |
| `calibration.csv` | critic の判定と人間の判定のズレ | librarian（毎回のレビュー） |

## 変更の流れ
librarian の追記は、その案件の PR とは別の PR（`taste: …`）で出る。マージした時点で次の依頼から効く。
マージしない＝その学習を採用しない、という意思表示になる。
