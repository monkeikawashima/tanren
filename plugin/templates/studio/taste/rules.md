judge・critic・figma-critic・director・designer は、採点基準（プラグインの studio/rubrics/）より先にこれを読む。矛盾したらこちらが優先。

1行1ルール。理由と出典（案件 id と日付）を必ず残す。librarian が人間のレビューから追記し、PR で出す。手で書いてもよい。

```

```
