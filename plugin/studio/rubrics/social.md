# social — SNS投稿・ストーリーズ・OGP・動画サムネイル・カルーセル

## 媒体別の観点
- **サムネイルでの判読**：タイムライン上の縮小表示（幅 300px 程度）で主コピーが読めるか。critic はスクショを小さく見た想定でも判断する。
- **セーフゾーン**：ストーリーズ／リール（1080x1920）は上下の UI に隠れる範囲（上 約250px、下 約340px を目安）に重要な文字がないか。
- **OGP**：1200x630 で、左右を少し切られても（正方形トリミング表示を想定）タイトルが残るか。
- **カルーセル**：1枚目でスワイプしたくなる理由があるか。2枚目以降が同じ型で統一され、最後に行動の案内があるか。
- **文字量**：1枚あたりの文字量が多すぎないか（目安：見出し15字＋本文60字以内）。
- **シリーズ化**：同じフォーマットで次回も作れる型になっているか。

## ハードフェイル
- 縮小表示（幅 300px 相当）で主コピーが判読できない
- ストーリーズ／リールのセーフゾーン外に CTA やコピーが置かれている
- プラットフォームのロゴ・UI を模した要素を入れている（偽の「いいね」ボタン等）
