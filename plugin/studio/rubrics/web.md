# web — LP・コーポレートサイト・キャンペーンページ・記事ページ

## 媒体別の観点
- **ファーストビュー**：モバイル 375x667 の範囲で「誰向けの何か」と主 CTA が見えるか。
- **読み順**：スクロールに沿って、課題 → 解決 → 根拠 → 行動 の流れ（または brief が指定する流れ）になっているか。セクションが同じ型の繰り返しになっていないか。
- **CTA**：主 CTA の文言が行動を具体的に言っているか（「詳しくはこちら」は減点）。ページ内で主 CTA の見た目が統一されているか。
- **レスポンシブ**：375 / 768 / 1440 で破綻がないか。デスクトップをただ縮めただけのモバイルになっていないか。
- **画像の扱い**：仮置き画像の比率と配置が、本番画像に差し替えても成立するか。
- **ヘッダー・フッター**：ナビの項目数が brief の情報量と見合っているか。

## ハードフェイル
- モバイル幅でファーストビューに主 CTA も主張も入っていない
- 375px で横スクロールが出る
- 見出しの階層（h1〜h3）がスタイルと一致していない（h1 が複数、h3 が h2 より大きい等）
- リンクとただの文字が見分けられない
