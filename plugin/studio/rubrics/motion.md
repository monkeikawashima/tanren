# motion — 動くバナー・UIアニメーション・ロゴアニメーション・短尺モーショングラフィックス

HTML + CSS / Web Animations で作り、manifest の frames（ミリ秒）で静止画を切り出して採点する。critic は Playwright で実際の再生も1回確認する。

## 媒体別の観点
- **静止画としての成立**：どのフレームで止めても構図が崩れていないか。特に最終フレームは単体で広告・画面として成立するか。
- **尺とテンポ**：広告は 15 秒以内、ループは 3〜6 秒が目安。情報が出てから読む時間（最低 1.5 秒）があるか。
- **イージング**：linear を多用せず、出る動きは ease-out、消える動きは ease-in 系になっているか。
- **動きの意味**：動きが情報の順番や関係を説明しているか。全要素が同時に跳ねていないか。
- **reduced motion**：`prefers-reduced-motion: reduce` のとき、動きを止めて最終状態を表示しているか（UI の場合は必須）。

## ハードフェイル
- 最終フレームで要素がはみ出している、または消えている
- 文字が読める時間（1.5 秒）より早く切り替わる
- 1 秒に 3 回以上の点滅がある
- UI アニメーションで reduced motion に対応していない
