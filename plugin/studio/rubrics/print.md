# print — ポスター・チラシ・名刺・DM・パンフレット・パッケージ表面

HTML で組み、PDF に書き出して確認する。入稿データはこのループの対象外（人間が Illustrator / InDesign で仕上げる前提の「デザインカンプ」として採点する）。

## 媒体別の観点
- **距離**：ポスターは 3m 先から主題が分かるか。チラシは手に取って 5 秒で要点が分かるか。名刺は名前と連絡先が最初に目に入るか。
- **裁ち落としと安全域**：塗り足し 3mm を含むサイズで組み、文字やロゴを仕上がり線から 3〜5mm 内側に置いているか。
- **最小文字サイズ**：本文 7pt（約 9.3px）以上、注釈 6pt 以上。
- **色**：CMYK で再現しにくい鮮やかな RGB（蛍光に近い緑・青、純色に近い紫）に依存していないか。依存するなら progress.md に注記があるか。
- **情報量**：裏面や中面がある場合、表と役割分担ができているか。
- **紙面の余白**：情報を詰め込まず、紙の白を設計に使っているか。

## ハードフェイル
- 文字・ロゴが仕上がり線から 3mm 以内にある
- 本文が 6pt 未満
- PDF の書き出しサイズが contract の仕上がり＋塗り足しと一致しない
