# renewal — 既存サイト・アプリのフルリニューアル

入口は既存サイトの URL。`node scripts/crawl.mjs` が全ページを巡回して `jobs/<id>/renewal/` に棚卸しを作る。
成果物は「監査レポート」「新しい情報設計」「ページテンプレート」「サイト全体のプロトタイプ」「改修前後の比較」の5つ。web.md と prototype.md の観点もすべて適用する。

## 媒体別の観点
- **棚卸しの網羅**：inventory のすべてのページが、新しい情報設計のどこに行くか（統合・廃止を含む）対応表で示されているか。
- **監査の具体性**：問題点がスクショの場所と数値（コントラスト違反数、文字サイズ、読み込み時間、ページの深さ）で書かれているか。「古い印象」のような感想で終わっていないか。
- **情報設計**：主要な利用者のタスクが、旧サイトより少ないクリック数で終わるか。その比較が数字で示されているか。
- **テンプレート化**：ページの種類ごと（トップ、一覧、詳細、フォーム、記事など）にテンプレートがあり、全ページをそのどれかで作れるか。
- **継承と変更の判断**：ロゴ・色・既存の資産のうち、残すもの・変えるものと理由が書かれているか。
- **比較**：主要ページの改修前後が同じ幅で並べられ、改善点が注記されているか。

## ハードフェイル
- inventory にあるページが対応表から漏れている
- 監査で挙げた問題が、新しいデザインでそのまま残っている
- 旧サイトにない事実（実績・数字）を新サイトの文言に足している
- プロトタイプにリンク切れがある
