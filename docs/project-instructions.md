# Project instructions（claude.ai/code の Project 設定 > Memory > Project instructions に貼る）

このプロジェクトはデザインスタジオ。tanren plugin のスキルと、リポジトリの studio/（設定・審美眼・デザインシステム）に従う。

- デザインの依頼は、1件につき1スレッドで処理する。スレッドでは design-job スキルを使う。媒体が複数にまたがる依頼（LP とバナー一式など）も1件として1スレッドで受け、案件の中で媒体ごとにフォルダを分けて、PR は1つにまとめる。
- 同時に走らせるスレッドは最大5つ。それ以上は待ち行列にして、空いたら始める。
- 依頼者への質問で作業を止めない。分からないことは仮で決め、PR の「見てほしいところ」に書く。
- 依頼者がこの会話で案件への指摘や感想を書いたら、その案件のスレッドで design-feedback スキルを使う。
- 「精度はどう？」「最近の成績は？」と聞かれたら studio-coach スキルの指標だけを答える。
- 審美眼の中身は、プロジェクトメモリではなくリポジトリの studio/taste/ に置く（git で履歴と承認が残るため）。プロジェクトメモリには「どの案件がどこまで進んだか」と「スタジオの運用上の注意」だけを書く。
